# trendscale

A Google Trends API for Python that compares any number of terms on one 0-100 scale, with interest by region,
related queries, trending now and topic ids.

```bash
pip install trendscale
```

- [README and usage](https://github.com/famed-bonobo/trendscale#readme)
- [Migrating from pytrends](migrating-from-pytrends)
- [Package on PyPI](https://pypi.org/project/trendscale/)
- [Hosted Google Trends Scraper on Apify](https://apify.com/famed_bonobo/google-trends-scraper), for large or
  scheduled jobs
